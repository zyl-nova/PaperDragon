# Plan Visual Evidence

1. Select assets by argumentative purpose, not visual attractiveness.
2. Prefer exact LaTeX formulas and original archive figures. Preserve source names and captions.
3. Use a method diagram for mechanism, a result table or plot for the main claim, and an ablation asset for component evidence when available.
4. Crop tables only to relevant rows and columns while retaining headers, units, baselines, and highlighting semantics.
5. Attach a short interpretation and the claim each asset supports.
6. Mark unavailable assets explicitly. Never create an image and present it as an original paper figure.
