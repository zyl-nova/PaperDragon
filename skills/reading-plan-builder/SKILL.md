# Build Reading Plan

1. Preserve core coverage of overview, problem, method, theory, experiments, results, and contribution.
2. Change emphasis and evidence requirements according to the paper type.
3. Keep each task independently executable and assign it explicit output fields.
4. Mark peripheral tasks as supporting rather than deleting them; missing evidence must remain visible.
5. Return the execution tasks and recommended poster section order defined by `schema.json`.

Do not ask one task to summarize the entire paper. Every task must have one responsibility and an auditable evidence target.
