# Write Paper Sections

Apply the rules for the active section only:

- Overview: state the research target, central approach, and principal supported result in two sentences.
- Problem: name the concrete obstacle, affected setting, and consequence.
- Motivation: connect a documented prior limitation to the need for this work.
- Method: explain the whole pipeline before modules; state what each module contributes.
- Theory: preserve exact notation and assumptions; explain purpose without reconstructing missing formulas.
- Experiments: separate datasets, baselines, metrics, implementation, main comparison, and ablation.
- Results: pair every important conclusion with a number, comparison, or explicit qualitative observation.
- Contribution: distinguish novelty from implementation detail and include limitations or missing validation.

Lead with the section's takeaway and keep only evidence that changes the reader's understanding. Use complete sentences, never trailing ellipses or fragments. Preserve qualifiers, and return `not found in provided context` when evidence is absent. Never promote memory or interpretation into source evidence.
