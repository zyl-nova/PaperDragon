MapCoder: Multi-Agent Code Generation
for Competitive Problem Solving

MapCoder introduces a multi-agent prompting framework that replicates the full cycle of human program synthesis—recalling relevant examples, planning, code generation, and debugging—to improve code generation by large language models. Across eight competitive programming and program synthesis benchmarks, MapCoder achieves new state-of-the-art pass@1 results, including 93.9% on HumanEval, 83.1% on MBPP, 22.0% on APPS, 28.5% on CodeContests, and 45.3% on xCodeEval.

https://arxiv.org/abs/2405.11403v1

Problem & Motivation

  • Large language models (LLMs) show limited performance in code generation tasks, especially for complex competition-level programming problems, despite their proficiency in natural language processing.
  • Existing methods that generate code directly from problem descriptions and sample I/O, or that leverage relevant examples, do not feature a bug-fixing schema, leaving a gap in replicating the full cycle of program synthesis.
Motivation
  • Automation in program synthesis is paramount to maximize programmers' productivity and enhance accessibility.
  • Addressing this gap matters because solving complex programming problems requires deep comprehension of natural language descriptions and successful execution of comprehensive unit tests, which current LLM-based approaches struggle to achieve.

Method Overview

  • MapCoder cascades four LLM agents—retrieval, plan, code, and debug—in a structured pipeline with an adaptive traversal schema that dynamically interacts among agents to iteratively enhance generated code.
  • The retrieval agent generates relevant examples and tutorials without external models, and the pipeline augments in-context learning signals from previous agents to improve code generation.

Key Mechanism

MapCoder's theoretical mechanism is a multi-agent pipeline that cascades LLM agents in a structured way, augmenting each agent's in-context learning signals from previous agents. The Retrieval Agent recalls past problem-solving instances by instructing the LLM to generate similar problems and solutions, extending analogical prompting principles.

Main Experimental Results

  • MapCoder achieves state-of-the-art Pass@1 results across all eight benchmarks, with notable scores of 93.9% on HumanEval, 83.1% on MBPP, 22.0% on APPS, 28.5% on CodeContests, and 45.3% on xCodeEval.
  • Compared to Direct prompting, MapCoder improves competitive problem-solving performance by 41.3%, 52.6%, and 132.8% for ChatGPT on APPS, xCodeEval, and CodeContests, respectively, and by 73.7%, 41.2%, and 135.1% for GPT-4.
  • On CodeContest, MapCoder's Pass@1 (28.5%) matches the Pass@5 of AlphaCodium (29%), and its Pass@5 further improves by 12.8%.
  • Extensive experiments across eight benchmarks with multiple LLM ablations validate the claims of superior code generation capability.

Contributions

  • MapCoder introduces a structured multi-agent prompting framework that emulates the full program synthesis cycle—retrieval, planning, coding, and debugging—through four dynamically interacting agents, a key innovation over prior zero-shot methods.
  • This design consistently outperforms established baselines and state-of-the-art approaches across eight major programming benchmarks, demonstrating its impact.
