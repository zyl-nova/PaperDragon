Pix2Vox: Context-aware 3D Reconstruction
from Single and Multi-view Images

Pix2Vox is a unified framework for single-view and multi-view 3D reconstruction that outperforms state-of-the-art methods on ShapeNet and Pix3D benchmarks. It uses an encoder-decoder to generate coarse volumes, a context-aware fusion module to select high-quality reconstructions for each part, and a refiner to produce the final output.

https://arxiv.org/abs/1901.11153v2

Problem & Motivation

  • RNN-based multi-view 3D reconstruction methods (e.g., 3D-R2N2) suffer from permutation variance, long-term memory loss, and sequential processing, leading to inconsistent and inefficient reconstruction.
Motivation
  • Solving these limitations is important because 3D reconstruction is critical for robotics, CAD, VR/AR, and existing methods fail to fully exploit input images or handle view order variations, hindering accuracy and speed.

Method Overview

  • The context-aware fusion module aggregates per-view coarse volumes by adaptively weighting each part based on quality, down-weighting low-quality reconstructions as shown in score map visualizations.
  • This mechanism directly counters permutation variance and long-term memory loss by processing views in parallel and selecting the best parts, yielding about 2% IoU improvement over RNN fusion in LSM.

Key Mechanism

Pix2Vox replaces sequential RNN-based multi-view fusion with a parallel encoder-decoder that generates a coarse 3D volume per view, then a context-aware fusion module aggregates these volumes by selecting the best parts from each, and a refiner corrects the fused volume. This design eliminates order dependence and long-term memory loss, enabling full use of all input images.

Contributions

  • The key innovation is the context-aware fusion module, which replaces RNN-based sequential fusion to eliminate order dependence and long-term memory loss, and fuses coarse volumes to better preserve multi-view spatial constraints.
  • This design enables Pix2Vox to outperform state-of-the-art methods on ShapeNet and Pix3D while being 24 times faster in backward inference.
